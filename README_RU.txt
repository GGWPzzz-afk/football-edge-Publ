FOOTBALL EDGE 0.2 — ПОДКЛЮЧЕНИЕ API-FOOTBALL

В ЭТОЙ ВЕРСИИ:
- реальные матчи по выбранной дате через API-Football;
- попытка получить коэффициенты 1X2 из доступного ответа API;
- ключ читается только серверной функцией Netlify из переменной FOOTBALL_API_KEY;
- калькулятор Value и ручной расчёт Dixon–Coles сохранены.

ВАЖНО:
- Это ещё не готовая прибыльная система прогнозов.
- Модель пока НЕ получает автоматически λ команд и НЕ выдаёт прогнозы по реальным матчам.
- Коэффициенты могут быть недоступны на бесплатном тарифе или для отдельных лиг/матчей.
- В этой версии нет live-обновления и истории котировок.
- Не использовать как основание для ставок без проверки данных и тестирования модели.

РАЗМЕЩЕНИЕ:
Для работы Netlify Function нельзя просто перетащить статические файлы в Netlify Drop.
Нужен deploy из Git-репозитория (например, GitHub), чтобы Netlify собрал папку netlify/functions.
В корне репозитория должны лежать index.html, app.js, styles.css, manifest.webmanifest, sw.js, icon.svg, netlify.toml и папка netlify/functions/fixtures.mjs.

В Netlify уже должна быть создана переменная:
FOOTBALL_API_KEY = ваш личный ключ
Убедитесь, что у неё включён scope Functions (если Netlify показывает выбор scope).
После добавления/изменения переменной обязательно выполнить новый deploy.

ФУНКЦИЯ:
/.netlify/functions/fixtures?date=YYYY-MM-DD
Дата по умолчанию — текущая дата Ташкента.
